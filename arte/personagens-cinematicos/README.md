# Personagens cinematográficos

Copie os WebP do pacote selecionado para esta pasta (`arte/personagens-cinematicos/`). O carregador Vite detecta os arquivos presentes no build. Não renomeie os IDs; a seleção de eventos está em `src/comum/posesCinematicas.js`.

Os arquivos ainda não foram enviados nesta etapa. Sem os WebP, as premiações mostram o painel de resultados sem personagem esportivo; a apresentação original permanece funcional. Os modelos são fixos: personalização facial, máscara de uniforme, número e escudo sobre o personagem ainda precisam ser implementados. Não publicar como personalização concluída.
